# Plantilla conceptual para campañas audiovisuales

Usar `npm run video:project -- init --client EMPRESA --campaign PRODUCTO` para generar las carpetas reales en `media-workspaces/`, fuera de Git. No crear carpetas de grabaciones en el repositorio público. Ver `docs/video/VIDEO_WORKSPACES.md`.

Checklist: crudos inmutables, referencias con licencias, brief verificable, timeline editable, 2 versiones del anuncio, QA ffprobe y visual, entrega con MP4 finales. Sin evidencia `NOT_RUN`.
