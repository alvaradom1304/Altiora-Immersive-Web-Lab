# Producción por milestones
| Milestone | Responsable | Evidencia y gate de salida |
|---|---|---|
| M0 Discovery | Estrategia + UX | Brief, audiencia, tarea principal, datos disponibles, alcance y restricciones. Incertidumbres con dueño y fecha. |
| M1 Dirección de marca | Branding + Creativo | Dos rutas como máximo, moodboard, muestra del hero y justificación. Cliente elige una ruta revisable. |
| M2 Prototipo | UX + UI + Copy | Flujo principal navegable en móvil y escritorio, contenido real o identificado como provisional. Prueba con usuarios representativos. |
| M3 Producción | Visuales + Motion + Ingeniería | Recursos con derechos documentados, sistema de componentes, estados y alternativa sin movimiento. |
| M4 QA | QA + Ingeniería | Evidencia visual y funcional, errores resueltos, presupuestos medidos y scorecard aprobado. |
| M5 Launch | Dirección + Cliente | Versión concreta aceptada, respaldo, rollback, formularios y analítica comprobados. Publicación según autorización vigente. |
| M6 Aprendizaje | Growth + UX | Revisión tras 2 y 4 semanas como propuesta inicial; baseline, fricción y mejoras priorizadas. |

Cada gate usa templates/review-gate.md. Bloqueos vuelven al dueño del trabajo con reproducción y criterio de aceptación. El director resuelve conflictos entre estética y usabilidad priorizando la tarea del usuario y la intención de marca. No avanzar con contenido ficticio como evidencia comercial.
