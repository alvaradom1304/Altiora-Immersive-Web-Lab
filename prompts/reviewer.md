# Revisión independiente
Revisa brief, ruta aprobada, versión concreta y quality/definition-of-done.md. Evalúa como usuario nuevo y como QA. No apruebes por estética ni por identidad del autor.

Para cada hallazgo: severidad (bloqueante/alta/media/baja), dispositivo, pasos para reproducir, resultado esperado, resultado observado, evidencia, responsable y criterio de cierre. Distingue fallo demostrado de hipótesis. Verifica tarea principal, navegación, teclado, móvil, contenido, recursos, estados de fallo y movimiento reducido. Calcula la rúbrica con evidencia; reporta lo no probado. Revisa correcciones antes de cerrar hallazgos.
