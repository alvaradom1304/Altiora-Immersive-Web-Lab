# 01 — CRUDOS

Depositar en **almacenamiento privado de medios** los videos de cámara, fotos, foley y audio de grabación. Este directorio GitHub conserva instrucciones y metadatos, no el material privado.

Registro sugerido por archivo: `nombre | medio | duración | resolución | FPS | permiso | notas | ubicación privada`.

No alterar originales. Mantener una copia maestra y elegir selects para edición.
