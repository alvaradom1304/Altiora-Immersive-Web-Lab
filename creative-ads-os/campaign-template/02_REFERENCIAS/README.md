# 02 — REFERENCIAS

Aquí se registran los enlaces y análisis de anuncios de referencia (no guardar videos sin permiso). Por cada referencia documentar:
- URL/origen y titular;
- lo que inspira: ritmo, encuadre, iluminación, sound design, estructura o humor;
- qué NO copiar: diálogos, personajes, montaje distintivo, logos, música, guion;
- transformación propuesta: una idea nueva y anclada al producto/cliente.

El resultado debe ser original, no una reproducción frame por frame.
