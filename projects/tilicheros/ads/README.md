# Tilicheros — Producción de anuncios

Carpetas de trabajo por cada campaña con los tres estados que pidió el cliente: **01_CRUDOS**, **02_REFERENCIAS**, **03_FINALISTAS**.

- `consola-retro/`: nostalgia y juego (piloto narrativo).
- `audifonos-precio-humor/`: humor y valor económico (piloto táctico).

Las carpetas están versionadas con archivos README, pero **no contienen videos**. Para producción cargar crudos y referencias a un drive privado, después enlazar la ubicación autorizada en el manifiesto sin exponer credenciales ni datos personales. Las piezas finalistas se entregarán después de grabación/edición y QA.
