# Producción de visuales
Cada recurso usa templates/visual-brief.md y assets-manifest.csv. Flujo: brief → bocetos → selección → producción → retoque → recortes móvil/escritorio → optimización → QA en contexto.

Prompt adaptable: Crear [recurso] para [marca/audiencia], que comunique [mensaje] y [emoción]. Sujeto [detalle], entorno [detalle], iluminación [detalle], materiales [detalle], paleta [tokens], encuadre [detalle]. Reservar espacio [zona] para titular HTML. Versiones [proporciones]. Evitar [restricciones]. Mantener consistencia con [referencia autorizada].

Textos, botones y logos exactos se incorporan como HTML o recursos vectoriales. Revisar anatomía, producto, perspectiva y fidelidad. Imágenes conceptuales no se presentan como instalaciones, personal o trabajos reales del cliente. Registrar herramienta, versión, licencia, fuente, consentimiento cuando aplica y revisión humana. No usar imágenes generadas para gráficos de datos exactos.
