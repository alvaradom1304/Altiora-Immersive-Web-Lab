# Bibliotecario: coincidencias por términos

La [evidencia y los límites del cambio](../../skills/altiora-bibliotecario/references/word-boundaries.md) viven dentro del paquete portable para conservar sus referencias al copiarlo. El buscador deja de interpretar SEO dentro de «deseo», CRO dentro de «microempresa» y API dentro de «capital», sin equiparar recuperación léxica a selección nativa de skills.

La aplicación local actualizó cinco copias instaladas —tres personales y dos del proyecto empresarial— con respaldo, comparación del contenido previo y preservación de variantes. Se verificaron cinco recursos normalizados por copia y cada helper pasó los mismos 17 casos redactados. El doctor del proyecto pasó con sus recibos actualizados; no se cambiaron cuentas, hooks ni permisos. Esto no son 85 pruebas independientes de usuarios.
